# Standalone PyIceberg Demo

Independent of AWS — runs locally to demonstrate core Iceberg concepts
before the AWS-specific implementation in Part 3/4.

## Planned scripts
| Script | Demonstrates |
|---|---|
| `01_create_table.py` | Creating an Iceberg table with a local/PyIceberg catalog |
| `02_schema_evolution.py` | Adding/renaming/dropping columns without rewriting data |
| `03_time_travel.py` | Querying historical snapshots of a table |
